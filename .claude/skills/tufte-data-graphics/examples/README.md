# Before / after — the "key 2DOF transfer functions" review figure

A worked example of the `tufte-data-graphics` skill on a real, central project
artifact: the key FRF / apparent-mass review figure
(`artifacts/plots/key_2dof_transfer_functions_linear.png`, generated by
`scripts/visualize_results.py:plot_key_linear_transfer_functions`). This figure
is referenced repeatedly in `notes/memory.md` and is the human-review anchor for
the apparent-mass quantity contract, so design clarity matters.

Reproduce:
```
python3 .claude/skills/tufte-data-graphics/examples/before_after_key_frf.py
```
It recomputes the **same curves from the same dataset**
(`artifacts/synthetic/twodof_dataset.json`); only the *design* changes.

- `key_frf_BEFORE.png` — faithful replica of the current style.
- `key_frf_AFTER.png` — same numbers, Tufte checklist applied.

## What changed and why (mapped to the checklist)
| Problem in BEFORE | Tufte principle | Fix in AFTER |
|---|---|---|
| Full box frame on every panel | data-ink ratio; erase non-data-ink | top/right spines removed; thin muted axis lines |
| Heavy `which="both"` x+y gridlines | chartjunk (the grid); 1+1=3 | major **y-only** grid at #e6e6e6; x-grid off |
| Boxed in-data legends (5 and **9** entries) overlapping the data | integration of words+data; avoid eye ping-pong; show the data | frameless, curve-ordered labels in the outside whitespace; single-curve panel gets **no** legend |
| Default tab10 colors (not colorblind-safe) | color discipline; smallest effective difference | Okabe–Ito colorblind-safe palette, shared across panels |
| Vague y-labels ("magnitude, accel/force") | documentation; quantity contract | units in titles: a/F [(m/s²)/N], M = F/a [kg], a₂/a_base [g/g] |
| Reference lines only decoded via the crowded legend | label in place; multifunctioning elements | mass asymptotes labeled at the line ("m1+m2 total = 1.6"); uncoupled fₙ labeled at the dotted verticals |
| No provenance / data count | documentation principle | caption: synthetic truth, 1 dataset, no flight-to-flight variability, source path |
| Tray resonance unlabeled | show causality/structure | resonance peak annotated in place |

## Honest notes
- This is a **design** improvement, not a numerical one: the curves are identical.
  It does not fix any modeling or convergence issue — those are separate gates.
- The dense apparent-mass panel still carries 6 curves. Direct end-of-line
  labeling failed here because the curves converge at the right edge, so the
  honest pragmatic choice was an ordered frameless legend in the margin (Tufte
  tolerates legends when direct labels genuinely collide). A further improvement
  would be **small multiples** (source / load / coupled in three sub-panels with
  shared scales); left out to keep a one-to-one before/after.
- Linear magnitude is kept (per the project rule: avoid dB unless standard); the
  apparent-mass panel uses log-y because the values span decades.
