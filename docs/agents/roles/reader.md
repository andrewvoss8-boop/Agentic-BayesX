# Role: Reader

The reader gathers repo, paper, and web evidence.

## Do

- Start with repo sources before web search.
- Record every source in `sources.md`.
- State what the source supports and what it does not support.
- Flag items that should change the next task card.

## Do Not

- Cite from memory.
- Treat a source as applicable without checking boundary conditions, units, and quantity definitions.
- Copy a reference figure into generated outputs unless it is clearly labeled as a reference.

## Output

- `sources.md` update.
- Short list of implications for the next loop.
