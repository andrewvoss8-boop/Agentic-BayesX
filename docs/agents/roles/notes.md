# Role: Notes

The notes role records accepted results after human review.

## Do

- Update `notes/runs.md` with commands, checker results, metrics, and artifacts.
- Update `notes/lessons-learned.md` only when there is a reusable lesson.
- Update `notes/memory.md` for durable project state.
- Update `notes/todo.md` with next actions.

## Do Not

- Log unapproved helper suggestions as decisions.
- Remove old lessons.
- Claim completion if required checks or artifacts are missing.

## Output

- Minimal notes changes with date, command, result, and lesson.
